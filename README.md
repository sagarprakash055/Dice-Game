🎲 Two-Player Dice Clash
A simple, interactive two-player dice game where luck determines the victor! In this project, two players go head-to-head, rolling virtual dice to compete for the highest number. The player with the highest roll wins the round and adds a point to their total score.

This repository serves as a great beginner-friendly example of implementing game logic, random number generation, and state management.

🎮 How It Works
The rules of the game are straightforward and designed for quick, competitive rounds:

Two Players: The game is designed for two players taking turns on the same device.

The Roll: During a round, each player rolls a standard six-sided die (generating a random number from 1 to 6).

Winning the Round: The player who rolls the higher number wins that round and receives one point.

Ties: If both players roll the exact same number, the round is a draw, and no points are awarded.

Victory: The game continues until a player reaches a predetermined winning score, or players can just play endlessly for the high score!

✨ Features
Dynamic UI: The dice images update in real-time based on the random number generated.

Live Score Tracking: Points are automatically calculated and displayed on the screen after every roll.

Winner Announcement: The game visually announces the winner of each round and the overall champion.

Clean Codebase: Highly readable code, making it easy to fork and customize.
